### 4-1. 데이터 이해

- 데이터: `training.csv` = 2021년, `testing.csv` = 2022년 일별 기록 (각 365행)
- 열: `date`, 기온 `avg`/`max`/`min`, 습도 `avg`/`max`/`min`, `power`(전력), `label`
- `label`: 1 = 이상치. training에 40개, testing에 47개이고, **모두 6~9월에 있다**
- [ ] 특징별로 label 0과 1의 분포를 비교한다 (어떤 특징이 이상치를 잘 구분하는지)
- [ ] 연속값을 어떻게 다룰지 정한다: 정규분포(Gaussian) 가정 vs 구간 나누기(binning)

### 4-2. 확률 모델 (확률)

- [ ] 사전확률 P(label) 계산 방법 정리
- [ ] 우도 P(특징 | label) 계산 방법 정리 (예: label별 평균·분산으로 정규분포)
- [ ] 사후확률을 비교해 0/1을 정하는 방법 정리 (확률을 많이 곱하면 0에 가까워지므로 로그 확률 사용 검토)
- [ ] 위 내용을 문서로 정리한다. 필요한 확률을 **어떻게 구했는지 명확히 설명**해야 2점

### 4-3. 구현 (구현)

- [ ] `training(instances, labels)`: 학습한 파라미터를 반환
- [ ] `predict(instance, parameters)`: **0 또는 1만** 반환 (다른 값이면 프로그램이 종료됨)
- [ ] Naive Bayes는 직접 구현한다 (라이브러리의 Naive Bayes 분류기는 쓰지 않음)
- 실행: `cd proj2/data` 후 `python bayes.py -t training.csv -u testing.csv` → accuracy, precision, recall 출력
- 스켈레톤 주의점
  - `instance[0]`은 날짜 문자열이다. 숫자 특징은 1~7번
  - 1로 예측한 것이 하나도 없으면 `report()`의 precision 계산에서 0으로 나누기 오류가 난다

### 4-4. 특징 선택 (특징 선택)

- [ ] 특징 조합을 **2개 이상** 정한다 (예: 기온만 / 기온+습도 / 전체)
- [ ] 조합마다 고른 이유를 적는다 (분포 비교, 상관관계 등 근거)
- [ ] 조합별 결과(accuracy, precision, recall)를 비교한다
- 아이디어: `date`에서 월·계절 같은 특징을 새로 만든다 (이상치가 모두 6~9월)

### 4-5. 하이퍼파라미터 튜닝 (파라미터 튜닝)

- [ ] 하이퍼파라미터를 정한다. 후보 예시
  - 판정 기준값: P(1 | x)가 얼마 이상이면 1로 볼지
  - 분산 smoothing: 분산이 0에 가까울 때 더하는 작은 값
  - 구간 나누기를 쓰면 구간 개수, Laplace smoothing 값
  - 사전확률을 데이터 비율 그대로 쓸지 조정할지
- [ ] 값을 바꿔 가며 결과를 **그래프**로 그린다 (예: x축 = 값, y축 = accuracy/precision/recall)
- [ ] 그래프 이미지를 GitHub에 올린다
